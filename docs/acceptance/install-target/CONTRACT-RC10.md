# Install-target contract rc10 · install recovery

Implementation `be771b0`, additive to `hanamesh.install-target` v1. A market install now runs in this order: baseline, official `dsh plugin add --save-exact`, profile readback, application definition, runtime provision. A failure after the baseline is compensated through the official CLI (`remove` for a new install, `add` of the original spec for an upgrade) and lib-provision (newly claimed items removed by ownership, replaced items provisioned again from the restored definition). Every item is then read back. `library.install-failed` keeps the original `code` and adds `recovery` with `not-needed`, `restored` or `failed`, plus actions, checks, residue, the compensation error and the kept originals under `<dataRoot>/library-recovery/<operationId>/`. Installs, compensations, uninstalls and provisions in one host are serialised. There is no automatic retry and no manual profile/store/metadata edit. No dependency, peer, vendor or configuration change.
